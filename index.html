关于本库　本站为纯静态离线数据库，全部词条与图版数据以独立结构化文件集中存放于 data/ 目录（roster.json 选目、artists.json 全文、index.json 索引、 images.json 图版清单、taxonomy.json 检索词表），补全新词条只需新增一个 JSON 片段并重跑 scripts/build_db.py，无需改动任何页面代码。

图版来源　图版取自 大都会艺术博物馆开放获取计划、 克利夫兰艺术博物馆开放获取计划 与 WikiArt 视觉艺术百科。 公有领域作品的图版用于研究与教育用途；每幅图版均标注来源机构，并尽量给出馆藏编号与高清原图链接。 部分近现代作品尚在版权保护期内，无合法开放图版可用，故以版式化的题名图版呈现，并给出馆藏检索入口。

编写体例　每位艺术家均按统一六部分结构撰写，各条要点力求具体、可核验。史实以通行艺术史文献为准； 当学界存在分歧时，在「争议与多元评价」一部分并列呈现不同观点。本库为研究与检索工具，不替代专业图录与原典文献。
