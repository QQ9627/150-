# 艺术家词条撰写规范（ENTRY SCHEMA v1）

本文件是 150 位艺术家词条的唯一写作规范。**严格照此执行，不得增删字段。**

---

## 一、总体要求

1. **语言**：简体中文。人名、作品名、术语首次出现时给出中译与外文原名。
2. **体例**：每个部分以**要点条目（bullet）**分述，**不接受**词条式的一两段简介。
   除 `statement`、`motifs`、`evolution` 三项为整段文字外，其余全部是字符串数组。
3. **信息密度**：每条要点 60–140 字，必须**具体、可核验**——出现具体年份、地点、作品名、机构名、
   人名、尺寸、材质、技法名词。禁止"他很有才华""影响深远"这类无信息量的空话。
4. **可核验**：只写有把握的史实。不确定的细节宁可不写或写为"约"。**不得编造**馆藏地、奖项、引文。
5. **引文**：`statement` 中的引文必须是真实存在的艺术家自述（书信、访谈、宣言、文章），
   格式：`"引文原文的中译"（出处，年份）`。若确实无把握，写其核心主张而不加引号，并注明依据的文献类型。
6. **标点**：字符串内部**一律使用中文引号「」或""，绝不使用 ASCII 双引号 `"`**（会破坏 JSON）。
   括号用中文全角（）。数字、年份用半角。
7. **禁用**：不得出现猎奇八卦、私生活窥探、未经证实的传闻。第六部分涉及个人经历时，
   **只写"该经历如何作用于创作"**，不写八卦本身。

### 字段规格

| 字段 | 类型 | 条数 | 对应网站栏目 |
|---|---|---|---|
| `life` | string[] | **6–9** | 一、生平与时代语境 |
| `style` | string[] | **6–8** | 二、创作风格与视觉标识 |
| `works` | object[] | **3–5** | 三、代表作品与艺术观念 |
| `statement` | string | 1 段，80–220 字 | 三、核心艺术主张 |
| `motifs` | string | 1 段，60–180 字 | 三、贯穿一生的创作母题 |
| `evolution.early/middle/late` | string ×3 | 每段 140–260 字 | 四、创作演变与分期 |
| `legacy` | string[] | **5–7** | 五、历史地位与影响力 |
| `controversy` | string[] | **4–6** | 六、争议与多元评价 |

### 各部分必须覆盖的内容点

**一、`life`（生平与时代语境）** 必须覆盖：
出生年代与籍贯；**重要人生转折**（迁居、战争、疾病、家庭变故、经济转折）；
创作生涯的**关键时间节点**（入行、首次个展、风格转向、成名或失败之年）；
所处时期的主流流派与社会思潮，并**明确判断他是顺应、反叛还是开创潮流**；
师承关系、交游圈、所属艺术团体或画派。

**二、`style`（创作风格与视觉标识）** 必须覆盖：
流派归属及在其中定位（**开创者／核心人物／边缘探索者**，须明写）；
题材偏好；色彩与笔触特征；标志性符号或视觉母题；
媒介与技法（具体到技法名词，如 chiaroscuro、点彩、自动书写、拼贴、湿壁画 buon fresco）；
是专注单一媒介还是跨媒介创作。

**三、`works`（代表作品）** 每件必须写满四个子字段：
`background` 创作背景｜`scene` 画面内容｜`innovation` 艺术突破点｜`significance` 历史地位。
`titleEn` 必须是该作的**英文通用名**（供馆藏检索用），务必准确。

**四、`evolution`** 三段分别对应早期探索／中期成熟／晚期蜕变，
必须说明各阶段**风格特征**与**转向诱因**（思潮影响、人生变故、材料技术革新）。

**五、`legacy`** 覆盖：艺术史贡献；对后世艺术家与流派的影响（点名具体人物／流派）；
顶级美术馆收藏（点名具体博物馆）；重要奖项、委托或荣誉。

**六、`controversy`** 覆盖：当时引发的批评与争议；
当代视角的再解读（女性主义、后殖民、精神分析、修复与真伪研究等）；
个人经历与性格**如何作用于创作**。
